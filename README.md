# examprog6112
exam
This application was created using Java in NetBeans. 

The project uses Maven to manage dependencies. 

Java Swing was used to create the application window. 

The user can enter the customer’s name. 

The user can select a mattress from the combo box. 

The available products are Cozy Nights Monarch, Restonic Barbados and Sealy Phuket. 

The user can enter the price of the selected mattress. 

The application calculates VAT at 15%. 

The application calculates commission at 5%. 

The total sale amount includes the price, VAT and commission. 

The Process button calculates the sales information. 

The results are displayed in a message box. 

The application saves sales information in data.txt. 

The File menu contains an Exit option. 

The Tools menu contains Process and Clear options. 

The Process menu option performs the same action as the Process button. 

The Clear option removes the entered customer name and price. 

The Clear option resets the product selection. 

JUnit 5 is used to test the VAT and total sale calculations. 

The application helps the company manage and process mattress sales easily.
